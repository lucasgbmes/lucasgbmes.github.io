# Lucas Gomes — Portfólio pessoal

Site estático, responsivo, em português, com foco em desenvolvimento, dados, automação e inteligência artificial aplicada.

## Comece aqui

1. Abra `index.html` no navegador (ou use a extensão Live Server do VS Code).
2. Abra `script.js` e edite o objeto `PROFILE` com seu link do GitHub, LinkedIn e e-mail.
3. Revise os textos e o status dos projetos em `index.html`. **Não marque um projeto como publicado sem que exista um link para a demo funcional.**
4. Quando cada projeto estiver pronto, substitua o status, acrescente os links de GitHub e demo e inclua métricas medidas em testes reproduzíveis.
5. Suba a pasta para um repositório. Para GitHub Pages: Settings > Pages > Build and deployment > Deploy from a branch, branch `main`, pasta `/ (root)`.
6. Se usar outro domínio, configure um URL público e atualize a imagem OG para um endereço absoluto na tag `og:image` do `index.html`.

## Arquivos

- `index.html` — conteúdo, links e metadados.
- `styles.css` — layout, responsividade e temas.
- `script.js` — menu mobile, alternância de tema, filtros de projetos e dados de contato.
- `assets/favicon.svg` — ícone.
- `assets/og-cover.png` — imagem para compartilhamento em redes.

## O que já funciona

- Layout responsivo desktop/mobile.
- Alternância entre tema escuro e claro.
- Menu mobile com Escape para fechar.
- Filtros de projetos (Todos / IA & produtos / Dados & processos).
- Painéis expansíveis com descrição de cada projeto.
- Contatos vinculados por configuração.
- Metadados básicos, navegação por âncoras, suporte a teclado e preferência por movimento reduzido.

## Transparência e privacidade

A interface de operações é apenas conceitual e contém valores ilustrativos. Os projetos de IA estão rotulados como propostas ou planejados. A experiência profissional é descrita em nível geral; **não inclua dados reais de beneficiários, clientes, credenciais, consultas internas ou informações restritas**.

## Tecnologia

HTML5, CSS3 e JavaScript sem bibliotecas externas de frontend. A única dependência opcional de rede é a fonte Google Fonts, com fallback local.
